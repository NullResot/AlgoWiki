# 日蚀观测台主题与动效设计说明

## 已确认范围

午夜脉冲剧场采用「日蚀观测台」视觉方向，并实现 A 方案动效。页面结构、信息密度和三栏观测台布局保持不变。本次改动集中在主题材质、导航统一、视图过渡和完成反馈，不增加新的业务功能。

## 视觉方向

这套主题来自算法竞赛夜间训练和天文观测的共同语境：信号、轨道、脉冲、星图、计时与复盘。基础色使用真空黑 `#070B14`、深海军蓝 `#0B1220` 和星尘灰 `#8E9AAE`；暖金 `#E8BC66` 表示知识信号，离子青 `#63D7F5` 表示训练轨道，远星紫 `#9B83F6` 表示观点纹理。

视觉签名是导航底部的日蚀光谱线。它以一条克制的细线连接金、青、紫三种语义色，让导航成为观测台的上沿，而不是单独悬在页面上方的白色区域。页面主体仍以中央算法星为唯一视觉中心。

深色层级依靠相邻表面的亮度差和低透明度描边区分，不使用厚重阴影。导航、弹出面板、输入框和按钮共用同一套深空材质：输入框比所在表面更暗，浮层比导航略亮，边界控制在低对比度范围。

## Midnight 主题

主题列表增加 `midnight`，展示名称为 `Midnight`。它是一套完整的全站主题变量，覆盖页面背景、四级文字、导航、输入框、按钮、浮层、边界、成功和警告色，不通过局部选择器硬改导航颜色。

导航在 Midnight 下使用接近不透明的真空黑材质，保留轻微背景模糊。AlgoWiki 字标改为暖白色，薄荷绿标志保留并降低光晕。搜索框使用内嵌暗舱材质，聚焦时显示青色细环；状态、主题和登录入口使用略高一层的暗色表面。导航底部显示 1px 光谱线，背景只保留极少量星尘纹理。

主题面板在临时主题期间显示「脉冲剧场临时主题，离开后恢复」说明。移动端菜单使用相同规则，不出现白色抽屉或白色浮层。

## 临时主题行为

进入 `/pulse-demo` 时立即记录当前主题，并以临时方式启用 Midnight。临时切换不写入 `localStorage`。离开该路由后恢复进入前的主题，用户原有偏好不被覆盖。

用户可以在脉冲页内打开主题面板并临时选择其他主题，这次选择只在当前脉冲页停留期间生效。离开页面后仍恢复进入前的主题。用户在其他页面主动选择 Midnight 时，按正常主题行为持久化。

初次直接打开 `/pulse-demo` 时，临时主题在首帧渲染前生效，避免白色导航闪现。连续进入和退出、浏览器前进后退以及组件卸载都必须正确释放临时主题。

## A 方案动效

标签视图切换使用 Vue `Transition`，退出约 140ms，进入约 240ms。新视图从 6px 位移和 `0.985` 缩放开始，使用 `cubic-bezier(0.23, 1, 0.32, 1)` 收束。切换只影响 `transform` 和 `opacity`，不改变容器高度。

观测台首次出现时，问答、星体和挑战卡片以 45ms 间隔分层进入；投票与今日轨道随后出现。按钮按下使用 120ms 的 `scale(0.97)` 反馈，键盘焦点使用清晰的细环，不依赖动画表达状态。

完成问答、挑战或投票后，原操作区与结果区进行短促淡入替换。中央星体产生一次 420ms 至 520ms 的信号响应，完成数字使用轻微回弹，轨道与纹理继续通过颜色和形态表达具体完成项。反馈结束后不保留持续弹跳。

Toast 进入使用约 220ms 的上移淡入，离开更快。禁止 `transition: all`，禁止动画宽度、高度、边距和内边距。

## 减少动态效果

系统启用 `prefers-reduced-motion: reduce` 时，取消位移、缩放、星体呼吸、粒子闪烁和纹理旋转。视图切换只保留不超过 120ms 的透明度变化；所有状态还必须通过文字、颜色和图形静态呈现。

## 响应式与布局约束

桌面端继续严格占满导航下方的可用高度，在 2048x1080、1920x1080、1440x900、1366x768 和 1280x720 下不产生页面滚动条，也不通过裁切隐藏交互内容。动效不得改变已验证的卡片尺寸和网格轨道。

移动端保留自然纵向滚动，不能产生横向溢出。视图切换、按钮反馈和临时主题在 390x844 与 375px 宽度下保持可用；触控区域不因视觉压缩而小于现有尺寸。

## 实现边界

不引入第三方动画库，不新增字体依赖，不修改正式业务接口。主题状态由现有 Pinia 主题 store 扩展；路由临时主题由应用壳统一管理；页面动效留在脉冲组件内部。Demo 继续使用本地状态，不接入 Codeforces、积分和社区后端。

## 验证标准

- 主题状态测试覆盖 Midnight 规范化、临时进入、临时切换、退出恢复和本地偏好不被覆盖。
- 从 Modern、Academic、Geek 或持久化 Midnight 进入脉冲页时，退出后均恢复原主题。
- 直接刷新脉冲页不出现白色导航闪烁，导航、主题面板和移动菜单不存在浅色残留。
- 三个标签视图均有过渡，按钮和三类完成动作有短促反馈，动画结束后不改变布局尺寸。
- 减少动态效果下没有位移、缩放和持续动画。
- `npm run test:pulse-demo`、新增主题测试和 `npm run build` 通过。
- 浏览器完成桌面、低高度桌面和移动端视觉检查，并复验无滚动条和无横向溢出。
